## ╭─ what I'm building

> **Hierarchical AI agents for hardware design.** Orchestrators that spawn specialist sub-agents per node — planning, retrieval, codebase reads, tool execution — all concurrency-safe. The agent is the system, not a feature.

> **Context engineering at scale.** Multi-stage compression pipelines, summarization middleware, sliding-window context management. Keeping million-token agent sessions coherent without burning the budget.

> **LLM evals that actually mean something.** Precision / recall, set-based scoring, benchmark-driven iteration. If you can't measure it, you can't improve it.
